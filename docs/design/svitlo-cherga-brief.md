# Бриф для Claude Design: «Графік відключень» (LocalHub Старокостянтинів)

## 1. Мета
Найзручніший у громаді сервіс, який за 3 секунди відповідає на питання: **«Чи буде в мене світло зараз і найближчими годинами?»** Сторінки рендеряться на сервері (SSR). Стек фіксований: **Nuxt UI 4 + Tailwind v4**, без сторонніх chart-бібліотек.

## 2. Аудиторія
- Мешканці Старокостянтинова та Хмельницької області. Здебільшого телефон (Android, 360–412 px), часто слабкий 4G, інколи телефон на павербанку з мінімальною яскравістю екрана.
- Від 14 до 75+ років: великі цифри, прості формулювання, жодних мікротекстів.
- Вторинна аудиторія: люди з інших областей, які приходять із пошуку («графік відключень 3.1 завтра»).

## 3. Ключові сценарії
1. **«Чи буде світло через годину?»** Відкриваю збережену чергу → бачу великий статус і таймер до наступної зміни.
2. **«Що завтра?»** Вкладка або URL `/zavtra`. Графіка ще може не бути, тоді треба чесно показати стан «ще не опубліковано».
3. **«Яка в мене черга?»** Пошук за адресою: населений пункт → вулиця → будинок → підчерга (іноді кілька).
4. **«Порівняти з сусідами / родичами»** — огляд усіх 12 підчерг області однією матрицею.
5. **«Що змінилось?»** — стрічка змін графіка за сьогодні: додано або скасовано інтервали.
6. **Поділитися** графіком своєї черги в Viber, Telegram, WhatsApp, Facebook.

## 4. Екрани та стани (mobile-first, потім desktop ≥ 1024 px)
1. **Сторінка черги** `/svitlo-cherga/khmelnytska-oblast/3-1`, блоки згори донизу:
   - **Hero-статус:** «Зараз за графіком **є світло**» / «**немає світла**» / «**можливе відключення**». Іконка + текст + колір (статус ніколи не передається тільки кольором). Таймер «Відключення через 1 год 25 хв (о 17:00)». Маленький рядок «Черга 3.1 · Хмельницька обл.» і кнопка зміни черги.
   - **Вкладки «Сьогодні, 22 листопада» / «Завтра, 23 листопада»** (`UTabs`).
   - **Шкала доби 00–24:** 48 сегментів по 30 хв, маркер «зараз», підписи годин кожні 3 год. Альтернативний вигляд — **кругова діаграма доби** (перемикач «Лінія / Коло»).
   - **Список періодів:** «17:00–21:00 · 4 год · без світла», минулі — приглушено, з позначкою «Завершено за графіком».
   - **Підсумок:** «Без світла за добу: 8 год · Зі світлом: 16 год».
   - **Стрічка змін** (згортається): «10:42 — додано 20:00–22:00», «09:15 — скасовано 06:00–08:00».
   - **Джерело:** «Джерело: АТ «Хмельницькобленерго», оновлено о 10:42». Дисклеймер: «Графік — це план, а не факт. Аварійні відключення можливі поза графіком».
   - **Шеринг:** 4 кнопки.
2. **Огляд області** `/svitlo-cherga`: пошук черги/адреси вгорі, банер «Ваша черга 3.1 — зараз є світло, до 17:00», матриця «підчерга × година» (12 рядків × 24/48 колонок, на телефоні горизонтально прокручується всередині картки, а не вся сторінка), список «Черги без світла зараз».
3. **Пошук адреси** (`UInputMenu` / `UModal` на мобільному): автодоповнення вулиці, вибір будинку, результат «Ваша підчерга 3.1» (або «Цей будинок має кілька приєднань: 3.1, 5.2») + кнопка «Зберегти як мою чергу».
4. **Стани:**
   - skeleton завантаження;
   - «Графік на завтра ще не опубліковано (зазвичай з'являється ввечері)»;
   - «Відключень не заплановано»;
   - «Діють аварійні відключення — графік може не виконуватися» (жовто-червоний `UAlert`);
   - «Дані можуть бути застарілими (останнє оновлення 2 год тому)»;
   - «Джерела розходяться — перевірте на сайті обленерго»;
   - помилка мережі.

## 5. Бренд і токени
- **Primary:** синій `#0057b7` (theme-color сайту). **Акцент:** жовтий `#ffd700`.
- **Семантика статусів:** окремі токени `--svitlo-on`, `--svitlo-off`, `--svitlo-maybe`, `--svitlo-unknown`. Контраст тексту і сегментів — WCAG 2.1 AA у світлій і темній темах. «Немає світла» — не червоний-тривожний, а спокійний темний або сірий з іконкою «вимкнено»; «є світло» — жовтий/теплий з іконкою лампочки.
- **Темна тема** обов'язкова: багато хто дивиться вночі.
- **Шрифт:** системний (як на сайті). Цифри таймера — tabular-nums.

## 6. Обмеження реалізації
- **Компоненти Nuxt UI 4:** `UCard`, `UTabs`, `UBadge`, `UAlert`, `USkeleton`, `UButton`, `USelectMenu`, `UInputMenu`, `UModal`/`USlideover`, `UProgress`, toast.
- **Шкала і коло** — власні легкі SVG/CSS-компоненти.
- **Доступність:** touch-цілі ≥ 44 px, клавіатурна навігація, `aria-live` для статусу (не частіше разу на хвилину).
- **Мова:** українська, усі тексти дублюються англійською (перемикач ENG у шапці сайту).
- **Продуктивність:** LCP < 2.5 с на 4G; hero-статус у першому екрані без JS.
